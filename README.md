## 🚀 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/jose-analista/php-projects.git
```

Entrar al proyecto:

```bash
cd php-projects
```

### 2. Verificar PHP

```bash
php -v
```

### 3. Verificar Composer

```bash
composer --version
```

### 4. Verificar Git

```bash
git --version
```

## ▶️ Ejecutar PHP

Para ejecutar un archivo PHP desde la terminal:

```bash
php 01-variables.php
```

Para ejecutar proyectos web utilizando el servidor integrado de PHP:

```bash
php -S localhost:8000
```

Luego abrir en el navegador:

```text
http://localhost:8000
```

## 🗄️ Base de datos

Los proyectos que utilizan bases de datos pueden trabajar con:

* MySQL
* MariaDB
* PDO
* MySQLi

Ejemplo de conexión mediante PDO:

```php
$pdo = new PDO(
    "mysql:host=localhost;dbname=mi_base_datos",
    "usuario",
    "contraseña"
);
```
